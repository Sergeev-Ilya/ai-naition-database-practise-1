# Critical User Journeys приложения

## Через визуальный интерфейс

1. **Сохранить запись** — пользователь вводит имя и телефон; система проверяет данные и надежно сохраняет запись.
2. **Уведомление о дубле** - если пользователь вводит имя и телефон, которые в такой комбинации уже есть внутри базы данных - то пользователю должно прийти сообщение о том, что "Данный телефон и имя уже зарегистрированы" - чтобы уведомить о дублировании.
2. **Найти телефон по имени** — пользователь вводит имя и получает связанные с ним телефонные номера.
3. **Найти имя по телефону** — пользователь вводит номер и получает связанные с ним имена.

## Через API

4. **Сохранить запись программно** — клиент передает имя и телефон; API подтверждает успешное сохранение или возвращает понятную ошибку.
5. **Найти телефон по имени программно** — клиент отправляет имя и получает найденные номера либо пустой результат.
6. **Найти имя по телефону программно** — клиент отправляет номер и получает найденные имена либо пустой результат.

## Надежность

7. **Сохранить и получить запись при большом объеме данных** — система не теряет записи и корректно возвращает их при росте базы.


## Какие шаги проходит пользователь на сайте
1. Открывает url приложения
2. Видит несколько полей пустых с именем "Телефон" и "Имя"
3. Видит 2 кнопки "Сохранить" и "Найти"
4. При нажатии на кнопку "Сохранить" происходит програмный вызов "Сохранить запись программно"
5. При нажатии на кнопку "Найти" и заполненном поле "Телефон" ниже на сайте показываются данные полученные через программный вызов "Найти имя по телефону программно"
6. При нажатии на кнопку "Найти" и заполненном поле "Имя" ниже на сайте показываются данные полученные через программный вызов "Найти телефон по имени программно"
7. При нажатии на кнопку "Найти" и заполненном поле "Телефон" и "Имя" ниже на сайте показываются сообщение о том, что "Можно искать только по одному параметру".
6. При нажатии на кнопку "Найти" и незаполненном поле "Имя" или "Телефон" ниже на сайте показываются сообщение о необходимости заполнить любое из двух полей перед нажатием кнопки.
