Источник: последний пункт `business-task.md`; принятый `ADR.md` выбирает PostgreSQL 18, отдельный сервис БД и миграции Flyway, а UI и REST API поставляются одним Spring Boot-приложением. Направление дополнения: явно зафиксировать обязательность готовой open-source СУБД и отразить эти существенные последствия для развертывания в `Impact`.
