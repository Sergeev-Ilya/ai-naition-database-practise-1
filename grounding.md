# Предупреждения по Grounding

1. **«Быстрый поиск» и «измеримые требования к скорости».** В `business-task.md` и `critical-user-journeys.md` нет согласованного SLA. Конкретные показатели скорости требуют подтверждения владельцем требований.
2. **«Реализация должна быть на Java или использовать готовое open-source решение с Java-интеграцией».** Текущий `business-task.md` требует готовое open-source решение для базы данных, но не задает Java и Java-интеграцию как обязательные ограничения. Выбор Java есть в `ADR.md`, однако это архитектурное решение, а не исходное бизнес-требование.
