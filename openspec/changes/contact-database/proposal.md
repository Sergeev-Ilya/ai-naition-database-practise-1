# Proposal

## Why

Нужен справочник имен и телефонов с одинаковым поведением в веб-интерфейсе и API, быстрым поиском и надежным хранением большого объема данных.

## What Changes

- Добавляется создание записи «имя + телефон» с валидацией и защитой от дублей.
- Добавляется поиск телефонов по имени и имен по телефону через API.
- Добавляется веб-интерфейс для сохранения и поиска.
- Устанавливаются измеримые требования к скорости и сохранности данных.

## Capabilities

### New Capabilities

- `contact-records`: создание, валидация, дедупликация и надежное хранение записей.
- `contact-search`: API-поиск записей по имени или телефону.
- `contact-web-ui`: пользовательские процессы сохранения и поиска в браузере.

### Modified Capabilities

Нет.

## Impact

Новые хранилище контактов, HTTP API и веб-интерфейс. Реализация должна быть на Java или использовать готовое open-source решение с Java-интеграцией.
